# Lessons Learned Log

| Date | Mistake | Rule |
|---|---|---|
| 2026-11-19 | Standard touch listeners on mobile can cause default gestures (pinch zoom, pull-to-refresh, pan scroll). | Always set touch-action: none in CSS and register non-passive event listeners where e.preventDefault() is required, plus track specific pointerIds. |
| 2026-11-19 | Browsers block AudioContext autoplay until the first explicit user interaction. | Initialize or resume the Web Audio context on the first user pointerdown or start button click. |
| 2026-11-19 | Creating new THREE.Vector3() or scratch arrays in RAF loops triggers Garbage Collection pauses on mobile devices. | Pre-allocate scratch vectors, matrices, and quaternions statically outside hot loops, and use object pooling for pickups and particles. |
| 2026-11-19 | High DPI displays cause mobile GPUs to overheat and drop frames when rendering 3D canvas at native resolution. | Always clamp device pixel ratio with renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2)). |
| 2026-11-19 | When backgrounding a mobile browser tab, requestAnimationFrame pauses; upon resumption, a large elapsed delta causes physics explosions. | Implement fixed timestep updates with an accumulator clamped to a maximum delta (Math.min(elapsed, 0.2)). |
| 2026-11-19 | TypeScript strict checking (noUnusedLocals) fails build on unused scratch variable declarations. | Ensure all scratch vectors or matrices declared for zero-allocation are actively utilized or removed before building. |
| 2026-11-19 | TypeScript verbatimModuleSyntax fails builds when types or interfaces are imported without the type keyword. | Always use import type or import { type T } for TypeScript types and interfaces. |
| 2026-11-19 | Adding dozens of individual Three.js meshes to a scene causes high draw call counts on mobile. | Use THREE.InstancedMesh and shared palette atlas materials to render hundreds of entities in a few draw calls. |
| 2026-11-19 | PWA maskable icons will have edges cropped by Android OS adaptive icon shapes. | Ensure maskable icons keep important graphic content within a 70-80% inner safe circle against the background fill. |
| 2026-11-19 | Modern Capacitor 7/8 with Android Gradle Plugin 8.13+ requires Java 21 in CI. | Configure GitHub Actions with Java 21 (actions/setup-java@v4 with distribution: 'temurin') to compile the native Android APK cleanly. |
| 2026-11-19 | Hardcoded hex colors scattered across codebases create styling drift and make palette consistency hard to maintain. | Define every color once as a typed token in src/data/palette.ts and enforce zero hex literals outside palette.ts via automated tests. |
| 2026-11-19 | Decorative emojis in code, commits, or UI degrade professional aesthetics and break on older embedded systems. | Strictly forbid emojis across UI, code, comments, docs, and git commit messages, enforced via automated regex testing. |
| 2026-11-19 | In TypeScript with verbatimModuleSyntax and strict local checking, declaring unused imported types or callback arguments causes build failures. | Only import needed types and omit unused parameter names from array iteration callbacks. |
| 2026-11-19 | In Three.js and Vite PWA, generating depth-based water foam via depth textures can cause pipeline stalls on mobile GPUs. | Use baked analytical island height functions in the water shader to determine depth and foam with zero texture read passes. |
| 2026-11-19 | In as const typed objects, numeric properties get inferred as literal number types rather than general numbers. | Explicitly annotate variable types (let minD: number = ...) when storing and updating distances from typed constants. |
| 2026-11-19 | Production code importing pure logic or types directly from tests/*.test.ts bundles test runner code (vitest) into production client bundles, bloating size and causing runtime crashes. | Never import from test files in production modules; isolate pure simulation and business logic in src/logic/ and import into both tests and production code. |
| 2026-11-19 | Setting both Three.js mesh position.y and vertex shader pos.y to waterLevel applies the vertical translation twice, doubling the visual ocean level relative to simulation. | Apply procedural or dynamic vertical displacements in either the mesh transform or the vertex shader, never both. |
| 2026-11-19 | Instantiating UI controller objects without storing them or invoking their update loops leaves dynamic DOM elements hidden or unresponsive. | Always retain controller instances and tick their update methods in the animation loop. |
| 2026-11-19 | Re-instantiating meshes or geometry hierarchies on every tick inside equipment methods causes excessive heap churn and GC pauses. | Always guard equipment and hierarchy-rebuilding methods with identity checks (itemId === currentEquippedItem && equippedMesh). |
| 2026-11-19 | Overlapping melee/lunge collision hitboxes without a per-attack or per-lunge state flag deal damage every single physics frame. | Use a dedicated boolean flag (hasHitThisLunge) reset on attack state entry and tripped on first contact. |
| 2026-11-19 | Inconsistent directional angle conventions between player orientation (sin, cos) and combat raycasting (-sin, -cos) cause inverted projectile trajectories. | Centralize orientation and forward-from-yaw math into a shared logic helper used across all entities and systems. |
| 2026-11-19 | State persistence systems that write to storage without an explicit startup restore call leave saved progress orphaned and reset on every reload. | Always wire load and validation directly into application bootstrapping, with defensive guards for missing, older, or corrupted schemas. |
| 2026-11-19 | Quick-bar and modal UI elements lacking touch pointer event handlers or missing stopPropagation lock out touchscreen users and leak touches through to the 3D viewport. | Explicitly attach pointerdown handlers with stopPropagation on all interactive HUD and modal overlays. |
| 2026-11-19 | Radial action menus without a clear cancel/exit option trap users in persistent modes. | Always provide a prominent cancel button and allow dismissing modes via hotkeys (Escape) or slot switching. |
| 2026-11-19 | Moving vehicles (rafts, platforms) that fail to transfer their frame delta displacement and vertical deck height to passengers cause entities to slide off into the world. | Explicitly synchronize passenger transforms with vehicle delta displacement and deck height while disabling normal walking/swimming gravity. |
| 2026-11-19 | Death routines that reset only primary health while leaving hydration, hunger, and exposure at critical levels immediately re-trigger damage loops. | Reset all survival vitals and clear velocities completely upon character respawn. |
| 2026-11-19 | Deducting composite action costs when one component is already simulated by an underlying system results in double-drain penalties. | Only deduct instantaneous one-shot action costs (such as dodge stamina) when continuous costs (sprint drain) are tracked by a simulation loop. |
| 2026-11-19 | Overlooking physical collision on player-built structures causes players to fall through elevated platforms and walk through walls. | Calculate and register static AABBs for walls/doorframes and clamp ground height to the maximum of terrain and supporting floor top surfaces. |
| 2026-11-19 | Hardcoding station types in crafting UI prevents player access to advanced station recipes. | Pass active station detection dynamically into UI rendering and crafting invocations based on proximity to interactive structures. |
| 2026-11-19 | Setting first-person cameras to look inward at the character origin instead of outward along view yaw/pitch causes disorienting inverted head perspectives. | Position first-person cameras directly at the head socket and orient them outward along (-sinYaw*cosPitch, -sinPitch, -cosYaw*cosPitch). |
| 2026-11-19 | Updating UI DOM active states on every tick without checking if the selection changed causes constant 60Hz DOM thrashing and layout recalculations. | Always early return if selected index or active state equals the current value before invoking DOM updates. |
| 2026-11-19 | Adding items into empty inventory slots without enforcing maxStack allows overflow stacks and prevents proper spillover into subsequent empty slots. | Strictly cap item placement in empty slots to maxStack and continue iterating to distribute remaining items across subsequent empty slots. |
| 2026-11-19 | Unfiltered keyboard keydown events trigger repeated toggle actions when an OS auto-repeat fires, causing UI flicker. | Check and ignore e.repeat for mode toggles, menu keys, and hotkey actions. |
| 2026-11-19 | Overwriting an entire DOM element className string strips existing classes like hud-interactive and breaks touch propagation guards. | Use classList.toggle or classList.add/remove rather than assigning to element.className directly. |
| 2026-11-19 | Copying entity world position over the root mesh (object.position.copy(this.position)) overwrites any procedural animation Y offsets applied earlier in the tick. | Apply procedural visual offsets to mesh position after copying base transform or animate dedicated child meshes. |
| 2026-11-19 | Allocating object literals or closures inside fixed 60Hz ticks or render loops causes unnecessary heap churn and Garbage Collector pauses. | Pre-allocate reusable scratch return objects and flags outside loops or on class instances. |
| 2026-11-19 | Leaving generic placeholder names in Android native strings.xml causes improper title display on installed mobile home screens. | Update strings.xml app_name and title_activity_main to the official game title. |
| 2026-11-19 | Generating PWA or native icons with placeholder neon artwork causes visual drift from the official stylized low-poly art style. | Generate all PWA, launcher mipmaps, and splash assets directly from official palette tokens and vector motifs across all densities. |
| 2026-11-19 | Retaining placeholder README stubs leaves developers and players without critical setup, controls, and build documentation. | Provide comprehensive project README detailing controls, commands, directory structure, and native APK build workflows without emojis. |
| 2026-11-19 | Full-width HUD wrappers with pointer-events auto block touches to underlying action clusters. | Set pointer-events: none on wrapper containers (.bottom-bar, .top-hud-bar) and only auto on interactive buttons and panels, with higher z-index on action clusters. |
| 2026-11-19 | Clearing one-shot actions (jump, dodge, interact) on pointerup causes dropped taps when a release occurs between fixed update ticks. | Latch one-shot actions to true on pointerdown/keydown and clear them only when the game simulation consumes them. |
| 2026-11-19 | Moving thumbs sliding off touch buttons can leave level-based actions (attack, sprint) permanently stuck. | Use setPointerCapture on pointerdown, release on pointerup/cancel/lostpointercapture, and clear all held inputs on window blur and visibilitychange. |
| 2026-11-19 | Generating runtime palette canvas textures in Node.js unit tests throws document is not defined. | Defensive check for typeof document === 'undefined' and return a lightweight DataTexture fallback so entities and materials can be instantiated in headless tests. |
| 2026-11-19 | Multiple competing systems updating the context interact prompt within the same frame cause UI prompts to flicker or instantly disappear. | Use a single centralized context action evaluator per tick to resolve priority between rafts, resource nodes, crates, and building placement. |
